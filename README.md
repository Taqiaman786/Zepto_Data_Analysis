📌 Project Overview
This project presents a complete SQL-based exploratory data analysis on the Zepto product dataset collected from Kaggle. The objective of this project is to analyze product pricing, discount trends, stock availability, and category distribution using SQL queries.
The project demonstrates practical SQL skills used in real-world retail and e-commerce analytics.



🎯 Business Objectives

The analysis focuses on solving important business questions such as:

•	Identifying highly discounted products

•	Understanding category-wise product distribution

•	Finding premium-priced products

•	Tracking out-of-stock inventory

•	Performing product weight analysis

•	Extracting meaningful retail insights



Dataset Features

The dataset contains product-level information including:

•	Product Name

•	Product Category

•	Maximum Retail Price (MRP)

•	Discount Percentage

•	Product Weight

•	Stock Availability
